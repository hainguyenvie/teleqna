Measurement · four arms, 40,000 scored responses

Thinking is worth +2.02 points, and it costs 968 tokens a question

Each arm ran the full 10,000 rows. The rotated arms deterministically rotate every row's choices — same question, same options, gold moved. On this benchmark that is not a position-prior control (there is no position prior: always A scores 22.10%) but an order-robustness control.

What the third row means

Under no-think, rotating the choices costs a statistically real 1.59 points. Under thinking it costs nothing measurable — 538 rows lost against 499 gained, p = 0.238.

Reasoning does not only raise the score. It removes the model's sensitivity to where an option happens to sit. That is a second, quieter argument for keeping thinking on — and it is the opposite of what the sibling srsranbench track measured, where thinking cost 4.8 points on identifier-lookup questions.

Diagnosis 1 · the shape of the gain

Thinking pays in every subject except the hardest one

Deliberation cannot manufacture a 3GPP clause the model never read. Standards specifications is a knowledge gap, not a reasoning gap — and it is the only place where more thinking buys nothing.

That single row reframes the whole plan. For the 8,000 rows outside Standards specifications, better reasoning and better answer discipline are live levers. For the 2,000 rows inside it — 765 of which are still wrong — the only lever is putting the specification text where the model can reach it: retrieval at inference, or knowledge distilled from the specs into the weights.

Diagnosis 2 · the gate before any training

Is 73.97% knowledge, or is it recall of a public file?

The GSMA teleqna split is the public TeleQnA dataset verbatim — 9,948 of 9,948 distinct questions appear word-for-word in netop-team/TeleQnA, same option order, same gold, and the public copy ships an explanation for all 10,000. It has been on GitHub since October 2023. Contamination is the null hypothesis here, not the exception.

The test that is evidence rather than inference

Mask one wrong option and ask the model to reproduce it. A distractor is arbitrary text invented by TeleQnA's generator — it is not a fact about telecommunications, so no amount of domain knowledge reconstructs it. The raw rate came back at 4.84%, inside the band that had been pre-registered as “partial exposure”. Then the length breakdown falsified the assumption that threshold rested on.

Gate passed

No usable evidence that Qwen3-8B has memorised TeleQnA. Reconstruction never exceeds a measured guessing floor at any length where guessing is hard; rewriting every question in different words costs nothing (p = 0.55); rotation costs 1.59 points, a position effect rather than item recall; and the per-subject difficulty profile reproduces the 2023 paper's ordering and spread. This is not proof the model never saw the file — it is the more useful statement that 73.97% is not explained by recall. Re-run the probe against every fine-tuned checkpoint, since training is where contamination would newly enter.

A control that had to be thrown away — kept in the record

The first control masked a distractor transplanted from a different question. It scored 0 / 599, mean token F1 0.032 against 0.299 on the real probe. That looked decisive and was not: a transplanted distractor is not a plausible answer to the question it was pasted into, so the control removed guessability along with memorisation. It measured “can the model reproduce unrelated text”, which is trivially no. It is recorded here rather than quietly dropped, because the pre-registered threshold it was meant to defend had already been shown invalid and the temptation was to move the goalposts by argument instead of measuring.

Diagnosis 3 · decomposition

Why an untrained model already scores this high

The benchmark is easier than its name suggests, in four measurable ways. Numbers below are from the no-think arm, where every row can be attributed cleanly.

Slice of the benchmarkRowsAccuracyWhat it shows

Two further reasons sit outside the table. GPT-4's 74.91% is an October 2023 number — an 8B model in 2026 matching a 2023 frontier model on knowledge MCQ is the normal scaling trend, not a telecom result. And “beats active telecom professionals at 64.86%” measures breadth: those humans answered closed-book across five subdomains no single engineer covers. A RAN engineer does not know the IEEE C95.1 RF exposure limits. Breadth is exactly what a language model has and a specialist does not.

Where the 2,603 remaining errors actually live

Fixing all 3,000 Standards rows to 100% would reach 84.4% — still 6.8 points short of the leaderboard's top entry. A retrieval plan aimed only at 3GPP specifications cannot finish this benchmark. That is the ceiling the Telco-RAG line ran into at 76%.

Consequences

What the baseline decides

Settled by measurement

  • Keep thinking on. +2.02 points and it removes order sensitivity, at 968 tokens a question.
  • The split is clean. The memorisation gate passed; downstream numbers can be built on.
  • Report against 39.72%, never against zero. A specialist at 80% has recovered 40 points of real signal, not 80.
  • Run at n = 10,000. 53 of 85 leaderboard entries on this column sit at n ≈ 1,000; a full-scale row is itself a differentiator.

Still open

  • Two corpora, not one. 3GPP and IEEE specifications for the 3,000 standards rows; telecom literature for the 6,500 research rows. Neither alone closes the gap.
  • Retrieval as teacher or as scaffold. Both are permitted — the harness accepts any OpenAI-compatible endpoint and never inspects what is behind it. The choice is about what the submitted number should mean.
  • Distractor generation is a first-class step. Swapping TeleQnA's distractors for foreign ones lifts accuracy 15.8 points, so roughly a sixth of this benchmark's difficulty is discrimination, not knowledge. A teacher that writes lazy distractors teaches the answer without teaching the discrimination.
