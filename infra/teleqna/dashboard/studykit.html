01Task and constraint

TeleQnA is the largest column of the GSMA Open Telco leaderboard: 10,000 of the 19,588 questions the average is computed over. The submitted artefact must be one Qwen3-8B answering closed-book.

Test questions may be used to select public source documents through retrieval. The answer key and the explanation field are measurement instruments only — they never enter a generation prompt, a data filter, or a training set. The benchmark's 10,000 rows are never trained on.

Baseline is 71.85. With eight retrieved windows in context the same model scores 83.75. The entire track is the question of how much of that +11.9 can be moved into the weights.

04What the diagnosis found

Never is the harder population and it is not a knowledge gap: 413 of 428 inspected cases had the gold string verbatim in a window and repeated at least five times in the kit. Reading samples showed one pattern — the model picks a sibling entity from the same passage: EDGE-1 → EDGE-3, state N8 → N9, first-order → second-order Markov, 10 cm → 1.5 m. This is an attribute-to-entity binding failure.

Sibling-contrast was built from that reading: exam items whose distractors are other siblings from the same window, with every option and the evidence required verbatim in that window. It is the largest single-stage gain since vote distillation (+0.62, +0.79 on the rotated control).

Sibling-contrast item · window w048526 (IEEE C95.1 effects table)
Q: What is an effect of RF/MW radiation exposure on children?
   A) Decreased memory, attention, and slower reaction time in school children  ← correct
   B) Retarded learning in rats indicating a deficit in spatial "working memory"
   C) Increased blood pressure in healthy men
   D) Damage to eye cells when combined with commonly used glaucoma medications
   E) Changes in sleep patterns and REM type sleep

evidence: "20) - Decreased memory, attention, and slower reaction time in school children"

All four distractors are true statements taken verbatim from the same table. They are wrong only because they answer a different question, so topic recognition cannot solve the item.

Extraction, not storage, is the bottleneck. On 1,214 questions the checkpoint had not fixed, base plus the retrieved windows answers 83% correctly — the fact is recoverable from the source, so the failure lies in retrieving it from the weights.

Three packing bugs were worth about 4 points combined: self-replay anchors that taught the base's own wrong beliefs (+1.50 once fixed), a chat/raw-text mode mismatch (2.7 points recoverable), and a missing <|im_end|> that let the model write past the answer letter — the same checkpoint scored 39.23 under the strict parser and 77.81 on the first letter.

06Measurement discipline

  • Every arm reports recover, broke, the rotated-choice control, and strict against first-letter parsing. A/A noise floor is 0.50 points.
  • Coverage is measured functionally, not by string overlap — the string measure gave a meaningless 20.5% because TeleQnA options are GPT-3.5 rephrasings rather than source quotes.
  • Every context claim carries a rotated-context control; the noise floor for "some passage is present" is about 9%.
  • Contamination: 2,937 test questions appear verbatim inside the kit, because the source windows contain the same sentences GPT-3.5 used to write them. The gain is equal on both groups (+7.4 with overlap, +7.1 without) and no copy of the dataset was found in the corpus.
  • Label noise is estimated at 3–5% by a 31B judge reading source windows, putting the ceiling with perfect knowledge at roughly 95–97. The broke population is about twice as rich in ambiguous labels as a random sample, so roughly a third of broke is unavoidable when the model follows the source.
